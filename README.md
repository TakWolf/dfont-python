# DFont - Python

[![Python](https://img.shields.io/badge/python-3.10-brightgreen?style=flat-square)](https://www.python.org)
[![PyPI](https://img.shields.io/pypi/v/dfont?style=flat-square)](https://pypi.org/project/dfont/)

A library for handling [Macintosh Font Formats (DFont)](https://fontforge.org/docs/techref/macformats.html).

## Installation

```shell
pip install dfont
```
